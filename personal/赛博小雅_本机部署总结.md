## 1. 系统架构与端口

整套系统由 **4 个服务** 组成，**必须按顺序启动**：

```
llama-server (:8080)          本地 LLM（Qwen3.5-9B Q4 GGUF）
        │  OpenAI 兼容 /v1/chat/completions
        ▼
s2s backend (:8766)           VAD → STT → LLM → TTS
        │  TTS PCM 转发 POST LiveTalking /humanpcm
        ├──────────────────────────────┐
        ▼                              ▼
s2s demo (:7860)              LiveTalking (:8010)
网页 UI + 数字人 iframe         wav2lip 口型 + WebRTC
```

| 服务 | 端口 | 说明 |
|------|------|------|
| llama-server | `8080` | LLM，`--reasoning off` |
| LiveTalking | `8010` | 数字人 WebRTC / `embed.html` |
| speech-to-speech | **`8766`** | 本机 `8765` 已被其它进程占用，故改用 8766 |
| demo UI | `7860` | 对话页面 |

**对话链路**：麦克风 → faster-whisper 中文 STT → llama.cpp 中文回复 → Qwen3-TTS → 音频同时给浏览器与 LiveTalking 口型。

#### 3.5.2 Python 依赖（`.venv-livetalking`）

**关键难点**：PyTorch 2.15 + CUDA 13 依赖包体积极大，直连 pip 易超时。推荐流程：

1. 用 aria2 把 torch / nvidia-* / triton 等 wheel 下到 `cyber-xiaoya/wheels/`
2. 先装小依赖（filelock、sympy、numpy…）
3. `pip install --no-deps` 指向本地 wheel
4. 再装 `LiveTalking/requirements.txt`，并 **pin torch** 防止被加速库重新拉取：

```bash
export PIP_DEFAULT_TIMEOUT=180
INDEX=https://mirrors.aliyun.com/pypi/simple/
printf 'torch==2.15.0\ntorchvision==0.29.2\ntorchaudio==2.11.1\n' > /tmp/torch-constraint.txt

# 示例：本地 CUDA/torch 已装好后
cd /home/c65789/cyber-xiaoya/LiveTalking
../.venv-livetalking/bin/pip install -r requirements.txt \
  -c /tmp/torch-constraint.txt \
  --find-links ../wheels \
  -i "$INDEX"
```

验证：

```bash
.venv-livetalking/bin/python -c 'import torch,aiortc,av; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))'
```

| 后端 | 说明 | 本机选择 |
|------|------|----------|
| `torch` | 下 CustomVoice `model.safetensors` ~3.6GB，显存更高 | 曾卡住下载，后改 ggml |
| `ggml` | 下 Serveurperso GGUF；默认 BF16 很大 | **`--qwen3_tts_backend ggml` + Q4_K_M** |

- 本机在 handler 中对 ggml 传入 `quant="Q4_K_M"`（见 `s2s/.../qwen3_tts_handler.py`）

STT：`faster-whisper` 模型 `base`，语言 `zh`（首次从 hf-mirror 拉 Systran/faster-whisper-base）。

#### 3.6.3 端口注意

默认 s2s WebSocket 端口为 **8765**。本机 8765 被无关服务占用，配置改为：

## 6. Q&A：安装排障

### Q1. 知乎原文打不开 / 403？

**A：** 用 live-avatar 仓库文档与补丁对齐即可；不必依赖知乎正文。架构与默认 avatar（`wav2lip256_avatar1`）以 LiveTalking + live-avatar DEPLOYMENT 为准。

### Q2. 没有官方「Qwen3-9B」GGUF？

**A：** 使用 **Qwen3.5-9B Q4_K_M**。本机文件：`models/Qwen3.5-9B-Q4_K_M.gguf`。启动加 `--reasoning off`，chat 侧可用 `enable_thinking:false` / `reasoning_effort=none`。

### Q3. `nvcc` 太旧编不过 Blackwell？

**A：** apt 默认 CUDA 12.0 不够。安装 NVIDIA CUDA **12.8** 的 nvcc/工具链后再编 `GGML_CUDA=ON`。

### Q4. GGUF / wheel / safetensors 下载极慢或卡住？

**A：**

- 设 `HF_ENDPOINT=https://hf-mirror.com`
- 大文件用 `wget -c` 或 `aria2c -x16 -s16 -c`
- PyTorch CUDA 包：先下到 `wheels/`，`pip install --no-deps` 本地安装，避免 pip 重复拉 400MB+ 包
- Qwen3-TTS torch 权重曾卡在 HF xet；可改 **ggml Q4** 或从 ModelScope CDN / zip Range 抽取

### Q5. pip 装 requirements 又把 torch 重新下载？

**A：** 使用 constraint 文件固定版本，并 `--find-links wheels`；或对超大包 `--no-deps` 先装本地 wheel。

### Q6. conda 装不动？

**A：** 本机改用 **python3.12 venv**（需 `python3.12-venv`），两个独立环境：`.venv-livetalking` / `.venv-s2s`。

### Q7. `sudo -S` 不读密码？

**A：** 若 alias 成 `sudo -A`，用 `command sudo -S` 并 `unset SUDO_ASKPASS`。

### Q8. 端口 8765 已被占用？

**A：** 本机曾被 cppcheck web 占用。改 `S2S_PORT=8766` 与 demo 的 `SPEECH_TO_SPEECH_URL`。启动前 `ss -ltnp | grep 876` 检查。

### Q9. LiveTalking 与赛博小雅形象不一致？

**A：** 文档默认是官方 `wav2lip256_avatar1`。shibing624 的 `wav2lip_avatar_female_model` 与官方 avatar1 **可完全相同**（本机 MD5 一致）。其它形象见附录 A。

### Q10. TTS 内置 VOICE 不好听？

**A：** CustomVoice 仅 9 个固定 speaker。更好效果需 **Base 模型 + 参考 wav 克隆**，见附录 B。不要用未授权影视原声。

### Q11. 双声道 / 双重播放？

**A：** demo 的 audio worklet 对 s2s 本地播放输出静音，声音由 LiveTalking WebRTC 播出，避免双声。不要再把两边都 unmute。

### Q12. 数字人铺满屏幕或变形？

**A：** 在 `s2s/demo/style.css` 用原始宽高比 + `min(100vh, native)` 等比适配；`embed.html` 里 `video { object-fit: contain }`。刷新注意 CSS 版本参数 `style.css?v=`。

### Q13. `/humanpcm` 返回 session not found？

**A：** 需浏览器先连上 embed（WebRTC offer）产生 session；s2s 通过 `LIVETALKING_URL` 查 sessions 再转发。先开页面再说话。

### Q14. 显存不够 OOM？

**A：** 优先 TTS 用 ggml Q4；LLM 保持 Q4；减小 LiveTalking `batch_size`；必要时先停其一服务。

### A.4 用自己的视频生成形象

**素材要求：**

- 正面人脸清晰，建议竖屏
- **闭嘴、不说话**（作静默循环）
- 时长约 5–30 秒，25–30fps
- `img_size` 对 wav2lip256 **必须为 256**

**方式 1：网页**

打开 http://127.0.0.1:8010/avatar.html 上传生成。

**方式 2：API**

```bash
curl -X POST http://127.0.0.1:8010/api/avatar/task \
  -F model=wav2lip \
  -F avatar_id=mynew \
  -F img_size=256 \
  -F video_file=@/path/to/silent_face.mp4
```

查进度：`GET http://127.0.0.1:8010/api/avatar/task/<task_id>`

**方式 3：命令行**

```bash
cd /home/c65789/cyber-xiaoya/LiveTalking
```

### B.2 参考音频克隆（音质通常更好）

需要：

1. **Base 模型**（非 CustomVoice 固定音色）  
   - `Qwen/Qwen3-TTS-12Hz-1.7B-Base` 或 `0.6B-Base`  
   - HF / ModelScope / hf-mirror
2. **参考音频** `ref.wav`：单人、干净、无 BGM，建议 **5–15 秒**
3. **参考文本** `ref_text`：音频里说的原文

官方试听参考音示例：

- https://qianwen-res.oss-cn-beijing.aliyuncs.com/Qwen3-TTS-Repo/clone.wav

**启动参数示例：**

```bash
--qwen3_tts_model_name Qwen/Qwen3-TTS-12Hz-1.7B-Base \
--qwen3_tts_backend torch \          # 或按 faster-qwen3-tts 文档使用支持的后端
--qwen3_tts_device cuda \
--qwen3_tts_ref_audio /home/c65789/cyber-xiaoya/voices/my_ref.wav \
--qwen3_tts_ref_text "参考音频中的完整原文内容" \
```

参考音存放建议目录：`/home/c65789/cyber-xiaoya/voices/`（可自建）。

### B.3 声音素材去哪找（合法）

| 来源 | 说明 |
|------|------|
| 自己录制 | 最推荐，质量可控 |
| 通义 Qwen3-TTS 官方 demo wav | 验证克隆流程 |
| LibriVox 等公版朗读 | 注意许可与语言 |
| 开源语音数据集截取 | 遵守数据集 License |
| 商用 TTS 厂商授权试听包 | 确认是否允许本地克隆 |

**不要**直接使用影视/游戏角色未授权原声。

### B.4 克隆效果差时检查

- 参考音是否过短、嘈杂、多人、带混响/BGM  
- `ref_text` 是否与音频一致  
- 是否仍停在 CustomVoice 而未换 Base  
- 显存是否在 Base torch 路径下 OOM（可试 0.6B-Base）
